# App Store screenshots

Mockups (1320×2868, 6.9″ iPhone) for the App Store listing: 7 English (`en-*`) and 6 German (`de-*`).

The repository can only hold text files from automation, so the PNGs are stored as base64 parts of a tarball.
To get the images back:

```sh
cd docs/appstore
./unpack.sh        # creates docs/appstore/png/assets/appstore/*.png
```

The same images are also available as plain PNGs on the website repo:
https://github.com/elija-7580/publit-site/tree/main/assets/appstore
(live at https://elija-7580.github.io/publit-site/assets/appstore/).
